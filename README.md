# Aqsa Khalid – Portfolio

Static site (HTML, CSS, JavaScript). No build step, no external dependencies.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g. `aqsa-portfolio`, or `<username>.github.io` for a root URL).
2. Upload everything in this folder to the repository root (`index.html` must be at the top level).
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. After a minute or two the site appears at `https://<username>.github.io/<repository>/`.
